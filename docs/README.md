# docs/

**Everything in this folder was written before the sprint** (Oct 20–23, 2026), as disclosed prep under Apart's rules. Later changes show up in the git history.

| File | What it is |
|---|---|
| `study-design.html`, `study-design.md` | The study design, v2 (Oct 22): hypotheses, figures, methods spec, analysis plan, power, validity, ethics, and the preregistration checklist. The HTML has the figures; the .md copy reads on GitHub. |
| `design-options.html` | The three designs we considered (A: smoke room, B: smoke room with a voice, C: witness to collusion), with validity scorecards. B was chosen. |
| `lit-review.md` | Merged literature review (Oct 21): 228 sources, corrections, and a design checklist. Most 2026 sources are preprints; check numbers against the papers. |
| `power/power.ts`, `power/power48.ts` | **Pre-sprint code.** Exact power calculations for Fisher's test and the equivalence test (`bun docs/power/power48.ts`). |
| `stimuli/generator-prompt.md` | The prompt DeepSeek uses to write the board posts, plus the review checklist. |
| `harness-plan.md` | The build plan for the experiment code (written before any code). |
| `coding-manual.md` | The codebook, judge prompt and judge validation plan. |
| `preregistration-draft.md` | The preregistration (AsPredicted format), to freeze Saturday before the main run. |

The paper draft is in `../paper/draft.md`.
